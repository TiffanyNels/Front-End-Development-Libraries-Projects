# Front-End Development Libraries Suite

A collection of interactive web applications built to demonstrate proficiency in modern frontend frameworks and libraries. This repository focuses on **ReactJS** as the core architectural building block, integrated with **Redux** for state management and **SASS/Bootstrap** for advanced styling.

## Tech Stack & Tools
- **Frameworks:** React.js, Redux
- **Styling:** SASS (SCSS), Bootstrap, CSS3
- **Libraries:** jQuery, FontAwesome
- **Development:** Create React App, Vite, Webpack

## Project Gallery

| Project | Key Technologies | Description |
| :--- | :--- | :--- |
| **Drum Machine** | React, CSS Grid | An interactive soundboard that triggers audio clips via keyboard and click events. |
| **Markdown Previewer** | React, Marked.js | A real-time editor that parses Markdown syntax into formatted HTML. |
| **Random Quote Machine** | React, Fetch API | A dynamic application that pulls inspirational quotes from an external API with social sharing features. |
| **JavaScript Calculator** | React, Logic Engine | A functional calculator built with complex state logic to handle multiple operations and decimal precision. |

## Technical Highlights
- **Component-Based Architecture:** Implementing reusable, modular React components for scalable UI development.
- **Global State Management:** Utilizing Redux (or React Context) to maintain data consistency across complex application flows.
- **Asynchronous Logic:** Integrating external APIs and handling asynchronous data streams effectively.
- **Advanced Styling:** Leveraging SASS variables, mixins, and nesting to create maintainable and responsive stylesheets.
